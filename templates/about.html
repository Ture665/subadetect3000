What does it do?

Subaharan Detector 3000 is a Raspberry Pi-powered face recognition system. When the camera recognizes Suba, it sends a detection event to the connected PC app. The PC app can then perform a selected action, such as Alt+Tab, Ctrl+Tab, showing the desktop, or opening a chosen application.

Raspberry Pi

Runs the camera, face recognition logic, socket event server, and the webserver for the dashboard.

PC App

Connects to the Raspberry Pi and reacts when Suba is detected using configurable actions.

Website

Provides login, monitoring, downloads, project information, server status, and future CRUD/database features.
